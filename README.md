# Sales Prediction Using Python

## Project Overview

This project predicts product sales based on advertising expenditure on TV, Radio, and Newspaper platforms using Machine Learning.

## Dataset

The dataset contains the following features:

* TV Advertising Budget
* Radio Advertising Budget
* Newspaper Advertising Budget
* Sales

## Technologies Used

* Python
* Pandas
* Scikit-learn
* Linear Regression

## Steps Performed

1. Loaded and explored the dataset.
2. Split the data into training and testing sets.
3. Trained a Linear Regression model.
4. Evaluated model performance using R² Score and Mean Absolute Error.
5. Predicted sales based on advertising spending.

## Results

* R² Score: 0.8994
* Mean Absolute Error: 1.4608
* Predicted Sales: 20.61
